First, the proposed system collects important student information such as attendance, marks, assignment scores, quiz results, previous academic performance and learning activities. 
Then the collected data is cleaned and prepared to remove errors and make it ready for analysis and machine learning. 
After preprocessing the data, various machine learning algorithms are trained with student data to predict their academic performance. 
Then we use Feature Engineering to get important features. 
Performance prediction uses machine learning models like Support Vector Machine (SVM), Random Forest (RF), Decision Tree (DT), and Logistic Regression (LR). 
The system establishes the student's performance level, risk level, learning profile, and learning objectives based on the prediction.
Academic data, attendance records, and learning activities get collected so the system can look at each student's overall progress. 
After analyzing this information, it hands out personal notes, topics, study materials, and other resources based on where a student is struggling.
